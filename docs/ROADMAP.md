# 路线图

策略：**先验证管线，再做垂直切片，最后铺量**。每个里程碑有明确验收标准，验收不过不进下一个。

排期口径：**业余节奏，每周 ~10 小时**（ADR 定于 2025-11）；里程碑耗时按此估算，全职可减半。

## M0 · 管线验证（1–2 天）

打通"Blender 脚本生成 → GLB → Three.js 播放"整条链路。

- bpy 脚本生成一个简单人形 + 3 个动画 clip（idle / 攻击 / 翻滚）
- 导出 GLB + JSON 帧数据侧车
- Three.js：GLTFLoader 载入，状态机按名切 clip
- 验收：clip 切换无跳变；帧表与动画对齐；`mixer.timeScale` 慢动作生效

## M1 · 战斗垂直切片（2–6 周，视时间预算）

一块竞技场 + 一个妖王，打满打击感。

- 玩家：三段轻击连招、翻滚无敌帧、识破（时缓+棍势）、棍势重击（蓄力+倍率）、定身术、葫芦
- 妖王 AI：4 招式（横扫/下劈/突刺/二阶段旋风）、前摇 telegraph、削韧→破绽、血量二阶段
- 打击感：onHit 总线六通道、手感档案五层级、顿帧/震屏/粒子/三层音效（见 docs/design/combat-feel.md）
- 调校工作台：帧数据热调、判定可视化、慢动作逐帧、参数存档
- 验收：蒙眼可凭听感分辨轻重视；0.25x 录屏逐帧检查六通道同帧；能打赢、想再战

## M2 · 魂循环（1–2 周）

- 死亡重开、土地庙复活与补给、挑战计数
- HUD 完整化（血条/棍势/葫芦/技能/Boss条+延迟白条）、音量与画质设置
- 验收：一次完整的"死→重整旗鼓→再战"循环手感成立

## M3 · 铺量（按野心伸缩）

- 小怪 ×3、妖王 #2、地图连接、成长面板（打坐/升级）
- 场景美术定稿（依赖美术风格决策）

## M4 · 联机（最后做，第一版是否纳入待定）

- WebSocket 房间码 + 四人协作（参考 wukong.cnmwx.com 方案）
- 注意：网络同步会反向约束战斗系统设计，若第一版就要联机需提前到此决策
