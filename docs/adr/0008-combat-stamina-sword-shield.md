# 战斗资源模型：DS3 式精力制；M1 武器原型为单手剑 + 盾

战斗资源采用经典精力制（Dark Souls 3 节奏）：攻击、翻滚、格挡、弹反全部消耗精力条，精力管理即博弈本身；整体节奏对齐 DS3 的快速翻滚恢复与进攻性（而非 DS1 的笨重感）。M1 武器原型定为单手剑 + 盾：盾反（弹反）→ 处决成为招牌技巧上限，且 Mixamo 动画覆盖最全、管线风险最低。

**Considered Options**: 黑猴式连携资源制（攻击不耗精力、攒势放重击）——否决，那是黑猴的魂不是魂的魂；混合制——留作后期武器流派差异再议。

**Consequences**: 前期讨论中沿自黑猴的"棍势"资源体系废弃；打击感规范（combat-feel.md）的反馈最高层级由"识破"改为"弹反→处决"，翻滚完美帧保留为隐性奖励；战技（weapon art）类系统 M3 再议；双手大剑作为第二武器在 M3 加入。
