# 定位修订：Dark Souls 3 同人致敬作品（取代 ADR-0005）

经裁决，游戏定位从「原创黑暗奇幻」改为 **Dark Souls 3 同人致敬**：世界观语汇与机制语言沿用 DS3（篝火、魂、不死人、Boss），玩家体验目标就是"网页版黑魂"。

同人生死线（不可越界）：

- **资产全部原创**——模型、动画、贴图、音频、代码全部自产（bpy 生成脚本 + Mixamo + CC0 素材），绝不使用 FromSoftware 的任何原始资源
- **非商用**——免费网页发行（自建静态托管，wukong.cnmwx.com 模式），不上架 Steam，无付费/内购
- 机制本身（篝火检查点/死亡掉魂/弹反处决）不受版权保护；专有名词仅在同人语境使用

**Considered Options**（裁决记录）：原创词条保商用路径（ADR-0005 原案）——放弃，同人气质优先；通用词折中——放弃，边界模糊且两边不靠。

**Consequences**: ADR-0005 整体作废（其美术条款由 ADR-0006 承接）；发行与变现路径自觉封死；若未来转向可商用，需整体更名并另立 ADR 重新裁决。
