# 运行时：Three.js + TypeScript，不采用游戏引擎

在网页平台（ADR-0001）之上，运行时选定 TypeScript + Three.js + Vite，自建战斗与渲染层，不使用 Unity / Unreal / Godot。

**Considered Options**:

- **Unreal 5**——画面上限最高（黑猴本尊所用），但磁盘与学习成本对本机是硬约束，且编辑器中心的工作流与"AI 写代码驱动一切"的路线相性差。否决。
- **Unity**——魂类教程生态最好，但目标平台是桌面客户端，与网页目标不符；且编辑器场景文件（二进制/半二进制）对 AI 审阅与版本管理不友好。否决。
- **Godot 4**——轻量开源，但 web 导出体积与性能相比直接用 Three.js 无优势，3D 生态与参考样本都更小。否决。
- **Three.js**——无编辑器，全代码驱动，AI 辅助开发效率最高（参考项目即此路线），npm 生态完整。**选定**。

**Consequences**: 没有现成编辑器与动画工具 → 动画管线由 Blender 侧承担（ADR-0003）、调校工具需自建（ADR-0004）；物理与碰撞自行实现（魂类近战用距离+角度判定即可，无需物理引擎）。
