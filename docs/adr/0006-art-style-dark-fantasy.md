# 美术风格：暗黑奇幻 · 冷灰基调 + 火光唯一强调色

美术采用暗黑奇幻方向：低饱和冷灰色石质/废墟基调，**火光暖色是唯一强调色**——同时承担主题表达（Inferno 的余烬与将熄之火）与打击感主色板（火花、受击闪光、篝火式检查点）。渲染走风格化（stylized，flat-shading/手绘质感），不做写实。

理由：冷灰底 + 单一火色强调的对比度最大化，让打击反馈的每一粒火花都被读见（与 combat-feel.md 的"反差"铁律同构）；风格化渲染在网页平台性能开销小、单人产能可及、与雾气氛围协同（浓雾既是魂味语言，也是网页端的视距裁剪优化手段）。

**Consequences**: 场景以石质/废墟/金属为主材质域；粒子特效统一火金色系；UI 配色为冷灰 + 火金；写实向材质管线（PBR 全套贴图）不需要，资产预算进一步降低。
