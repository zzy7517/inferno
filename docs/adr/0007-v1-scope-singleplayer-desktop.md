# 第一版范围：纯单机，桌面优先

第一版为纯单机，不写任何网络代码；但战斗状态机保持确定性设计（输入驱动、逻辑帧与渲染帧分离、随机数集中可注入种子），为未来联机留钩子不加成本。输入目标桌面优先：键鼠 + 手柄（Gamepad API，含双马达震动，震动是打击感六通道之一）；移动端触屏后置到 M3 之后评估。

**Considered Options**: 第一版即联机（M1 工作量 ×1.6，且网络同步会反向约束手感调校）——否决；全平台同步（触屏适配拖慢 M1）——否决。

**Consequences**: M1 交付物全部围绕单机体验验收；若未来启动联机（M4），需回头补确定性重构，届时另立 ADR。
