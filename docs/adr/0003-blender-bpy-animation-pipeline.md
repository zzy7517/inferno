# 动画管线：Blender + bpy 生成脚本为唯一事实源

所有三维资产（模型、骨骼、动画、材质）由可执行的 Python 生成脚本（bpy）构建并纳入 git，**不以 .blend 二进制文件作为事实源**；动画以 Mixamo 动捕打底 → 脚本重定向到自建骨骼 → 人工修重量感 → 导出 GLB（含骨骼动画 clip）+ JSON 帧数据侧车（前摇/判定帧/后摇秒数）。

理由：Blender 全功能皆可脚本化，AI 可接管约 85% 的产出（建模、绑定、批量导出），剩余 15%（动画重量感的审美裁决）由本人承担（前游戏策划 + 美术，具备手感判断力）；脚本是文本，AI 可读、可 diff、可维护，.blend 二进制三者皆无——这是选"生成脚本"而非"存工程文件"的决定性原因。

**Consequences**: Mixamo 动捕偏"飘"，需三味药——Blender 内收紧接触段关键帧（snap 压到 2–3 帧）、运行时叠加程序化 snap（挤压/过冲）、武器拖尾补速度感；复杂绑定的边角问题（蒙皮权重、矫正变形）仍需人工进 Blender 处理；重跑脚本即可复现资产，CI 可校验产物一致性。
