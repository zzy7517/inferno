# 游戏定位：原创黑暗奇幻，Dark Souls-like

游戏采用**原创黑暗奇幻世界观**，类型定位 Dark Souls-like：压抑氛围、篝火式检查点、死亡掉落货币的循环、高承诺出招、以弹反/精准闪避为核心的技巧上限。不做黑神话同人（不再借用天命人/棍势/黑风山等专有名词），也不绑定西游记公共领域题材。

**Considered Options**: 黑猴同人（版权风险、不可商用）——否决；原创西游题材——否决，主题与 Inferno 命名不咬合；纯原创黑暗奇幻——**选定**，Inferno 的火意象（余烬、灰、将熄之火）与世界观天然统一。

**Consequences**: 术语表中沿用自黑猴的内容词条（天命人/妖王/棍势/土地庙/灵蕴）需更名；玩法机制（检查点/死亡掉魂/弹反）本身不受版权保护，但**专有名词必须原创**，不得使用 FromSoftware 或游戏科学的标志性命名（如"传火""不死人"）；玩法致敬对象扩大为黑魂系（拉片校准参考可含黑魂/只狼/黑猴）。
