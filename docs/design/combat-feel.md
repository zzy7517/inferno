# 打击感设计规范

核心公式：**打击感 = 同一帧上的多通道同步反馈 × 反差与克制**。不是特效堆料。

## 一、六通道清单与起始参数

| 通道 | 手段 | 起始参数 |
|------|------|----------|
| 时间 | 顿帧 hitstop（攻防双方冻结）| 轻击 60ms / 重击 110ms / 处决 250ms+慢动作 |
| 动画 | 攻方：压缩→2–3 帧snap→过冲；受方：白闪+方向性击退 | 白闪 80ms（emissive 打白），击退沿攻击向量 |
| 特效 | 火花在**世界空间接触点**爆开、刀光弧、震波环 | 轻击 10–14 粒 / 重击 25–30 粒，寿命 0.2–0.4s |
| 音效 | 三层：whoosh（前）+ thump 中低频（中）+ 材质层（后）；随机 ±8% 变调 | 命中音必须精确落在判定帧那一帧 |
| 镜头 | 方向性震动（沿打击方向）、重击 FOV 冲击 | 轻击震幅 0.15 / 重击 0.5，指数衰减 8/s |
| 输入 | 手柄双马达震动 | 轻击弱震 / 重击强震 |

## 二、三条铁律

1. **同步**：六通道必须在同一帧触发。工程上只允许一个 `onHit(info)` 总线扇出，禁止各系统各自轮询。音效晚 2 帧即"飘"。
2. **反差**：反馈分五层级——擦伤 < 普通命中 < 重击/满棍势 < 削韧破绽 < 处决/最后一击。普通命中刻意"收着"，预算留给高潮时刻。
3. **因果**：击退沿攻击向量、火花在真实接触点、震动沿打击法线。玩家感知"物理不对"即"假"。

## 三、双向反馈预算

- **我打中敌人**：六通道全套。
- **敌人打中我**：红屏边缘脉冲、镜头重震、硬直打断——惩罚感是魂味的一部分。
- **我躲开了**：识破 = 无敌帧早期窗口触发，时缓 0.3×0.5s + 金色闪光 + 上行音效签名。

## 四、节奏权重（未命中时的手感）

- 后摇承诺：重棍后摇 ~0.5s，不可取消——重量来自"无法反悔"
- 取消窗口：翻滚仅在后摇后 40% 可取消
- 预输入缓冲 0.25s：后摇中按轻击，恢复即接招
- 轻吸附：出招瞬间朝锁定目标修正 5–10° + 小步前冲

## 五、网页平台专属：延迟治理

输入→渲染多 30ms 则全盘白做。渲染循环保持轻、rAF 内不做重活、指针锁定原始输入；开发期常开 Chrome 性能面板看帧时间。

## 六、Mixamo 动画修正三味药

1. Blender 内收紧接触段关键帧（snap 压到 2–3 帧）
2. 运行时叠程序化 snap（蓄力压缩/过冲）——"代码管时序、动画管表现"的价值所在
3. 武器拖尾补速度感

## 七、工程落点

- `onHit(info)` 总线：一次命中，六通道同帧扇出
- 每招一张手感档案（顿帧/震幅/音效组/粒子数/击退），进调校台热调
- 调校台：帧数据热调、判定可视化、帧计数器、0.25× 逐帧、参数存 JSON

## 八、校准方法

拉片：黑猴/只狼战斗视频 0.25× 逐帧数数（顿帧几帧、火花几帧消失、白闪几帧、镜头何时弹）。黑猴轻击顿帧约 4–5 帧（60fps）。实测数字直接抄进手感档案。

## 验收标准（M1）

1. 蒙眼只听音效可分辨轻重视
2. 0.25× 录屏逐帧检查：六通道同帧
3. 打赢一场后"想再战"
