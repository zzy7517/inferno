# M2 魂循环设计：死→掉魂→拾回→再战 + 篝火旅行

**定位**：把 4 Boss × 2 场景串成完整 demo 弧线。对标 DS3 核心循环——"死亡是流程的一部分"。

## 一、Demo 进度线（4 Boss 串联）

```
灰烬墓地[篝火] ──雾门──> 古达            击败 ──解锁──> 高墙传送
洛斯里克的高墙[篝火] ──雾门──> 玻尔多     击败 ──解锁──> 监视者(墓地雾门再生)
灰烬墓地 ──雾门──> 深渊监视者们           击败 ──解锁──> 沙力万
灰烬墓地 ──雾门──> 教宗沙力万             击败 ──> 结算屏(全通)
```

- 同一竞技场复用：墓地雾门后的 Boss 由进度决定（Boss 注册表 + 进度闸门），高墙竞技场只给玻尔多
- 雾门 Boss 换人 = DS3 的「回到熟悉的地方打新东西」；工程上零新增场景成本

## 二、死亡与掉魂

| 事件 | 行为 |
|------|------|
| 玩家死亡 | 魂全部掉在死点（血渍绿光柱，`vfx` 新增 soulSign）；「你死了」→ 自动回到最近休息的篝火 |
| 重生 | HP/原素瓶补满；Boss/小怪全 reset；雾门恢复 |
| 拾回 | 走到血渍按 E 取回全部魂；**再次死亡则旧血渍消散**（DS3 铁律） |
| 魂存量 | HUD 已有；血渍旁小字显示数额 |

## 三、篝火菜单（E 触发，方向键/点击选择）

```
◇ 休息        补满 HP/原素瓶，重生点设为此篝火（敌人 reset）
◇ 传送        列出已解锁篝火：灰烬墓地 / 洛斯里克的高墙（未解锁灰显）
◇ 升级        （M3）魂换属性：体力/精力/力量
```

- 菜单期间游戏暂停（时间冻结，同调校台暂停通道）
- 首个篝火即出生点；高墙篝火在击败玻尔多前为「未点燃」状态（可见不可用）

## 四、挑战计数与结算

- 每 Boss 计「身陨次数」；Boss 条下方小字 `第 N 次挑战`
- 全通结算屏加总：总用时 / 身陨 / 弹反 / 处决 / 拾回魂次数
- 「想再战」钩子：全通后解锁「再战任意 Boss」（篝火菜单第四项，Boss 直选——同时是调校入口）

## 五、工程落点

1. **进度状态**：`progress.ts`——{ unlockedScenes, currentBoss, defeated[], souls, lastBonfire }，localStorage 存档（键 `inferno.progress.v1`），死亡/击败/传送时写
2. **Boss 注册表**：`BOSSES: Record<string, { create(scene,vfx,pos,host), arena: SceneId, name }>`——game.ts 按 progress.currentBoss 实例化；调试可用 URL `?boss=vordt` 直选
3. **篝火菜单 UI**：DOM 覆盖层（复用 overlay 样式系），键盘 ↑↓/E 确认
4. **血渍**：vfx.soulSign(pos, souls) 绿光柱 + 粒子；玩家持有 reference（旧的消散）
5. **场景切换**：game.restart 扩展为 `travelTo(sceneId)`——dispose 旧场景（高墙有 dispose，墓地补一个）、重摆 anchors/篝火/雾门/Boss、玩家置新篝火
6. 验收：一次完整「死→掉魂→拾回→再战→胜→传送」无异常；两场景各死一次血渍行为正确
