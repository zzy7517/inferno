# M4 关卡流程与地图尺度设计：黑魂尺度的关卡与三场景流程线

**定位**：响应用户反馈「地图有点小」。把"竞技场串联"升级为 DS3 尺度的关卡：单场景可走面积 ~125 m² → ~4800 m²，6 Boss（含并行开发中的玛尔基特/葛瑞克）编成一条**两轮到访**的完整流程线，三种小怪（活尸/侍从/乌鸦，并行开发中）分区布点。
工程前提：流控已全参数化（`SceneAnchors` + `clampWorld`，game.ts；两场景 anchors 同构）——扩尺度 = 锚点/钳制扩维 + 场景几何铺量，**不动战斗系统**。
命名说明：本文档承接 ROADMAP M3「地图连接」项并顺延编号为 m4，与 ROADMAP「M4 联机」无涉。

## 二、总流程：6 Boss × 3 场景 × 两轮到访

**顺序裁决**：古达 → 玻尔多 → 玛尔基特 → 葛瑞克 → 深渊监视者们 → 教宗沙力万（法环双 Boss 插中部）。
理由：①难度曲线——玛尔基特是法环著名的中期门槛，恰在玻尔多「空间压制」与监视者「速度压力」之间；②叙事——城垣作"远行"中段，墓地/高墙**深处**作"归来"终盘，m2 的「雾门换人」升格为「深处解锁」，同一场景打两次但走的是新半区；③工程——每场景恰 2 Boss，进度闸门对半分摊，m2 的进度线骨架不动。
反对案：法环双 Boss 追加尾部（存量代码零改动）——放弃，沙力万（全游弹反考试）之后再塞两个法环 Boss，难度与叙事双倒挂。

```
第 1 轮 · 远行                                 门/传送解锁链
灰烬墓地 A ──古达胜──> 高墙 B ──玻尔多胜──> 史东薇尔城垣 E（传送解锁）
                                             玛尔基特 ─胜→ 深区开 → 葛瑞克
第 2 轮 · 归来
葛瑞克胜 ──开墓地门B──> 墓地深处 C：深渊监视者们
监视者胜 ──开高墙 D门──> 高墙深处 D：教宗沙力万 ──胜──> 全通结算（6/6）
```

| 场景 | 首到访 | 再到访 | 篝火（点燃条件，沿用 m2 语义） |
|---|---|---|---|
| 灰烬墓地 A/C 区 | 开局 | 葛瑞克胜后（门B） | A 灰烬墓地（初始）；C 法兰哨塔（门B 开后） |
| 洛斯里克的高墙 B/D 区 | 古达胜后传送 | 监视者胜后（D 门） | B 高墙（玻尔多胜，沿用 m2）；D 月坛（D 门开后） |
| 史东薇尔城垣 E 区 | 玻尔多胜后传送 | —（单次双 Boss） | E1 城垣（到达即燃）；E4 接肢教堂（玛尔基特胜） |
