# M1 Demo 设计：灰烬墓地（学习蓝本：DS3 开局「灰烬墓地 → 灰烬审判者古达」）

**定位**：用原创资产复刻 DS3 开局的"体验结构"与"教学设计"，不复刻其美术/音效/文本（ADR-0009）。
**学习对象**：古达 = 魂系教学 Boss 的教科书——每一招都是一个教学点。

## 一、Demo 流程（对标 DS3 开局结构）

| 步骤 | 内容 | 复刻自 |
|------|------|--------|
| 1 | 不死人于篝火旁苏醒，起身 | 墓地苏醒开局 |
| 2 | 短径 10–15m：翻滚教学沟壑 + 拾取原素瓶 | 墓地教学段落（M1 做最小版，小怪后置 M3） |
| 3 | 雾门（走近触发，M1 不做道具门槛） | Boss 雾门仪式感 |
| 4 | 跪像 Boss，胸插螺旋剑；**拔剑唤醒**，唤醒起身期间可白打，血条在其取戟后才出现 | 古达唤醒序列（玩家先手权 + 血条揭晓节奏） |
| 5 | Boss 战（二阶段，见下） | 古达一/二阶段 |
| 6 | 胜利：螺旋剑收入 + 魂结算 + 结算屏 | 传火祭祀场入口奖励 |

## 二、Boss「守烬者」（原创角色，角色原型 = 古达）

持长戟的审判者雕像。二阶段背部爆出**烬蛇**（对标古达的"人之脓"黑蛇，改为火主题，贴合 ADR-0006 火光唯一强调色）。

### 一阶段（戟）

| 招式 | 前摇 | 判定 | 后摇 | 教学点 |
|------|------|------|------|--------|
| 直戳 | 0.55 | 0.16 | 0.85 | 基础阅读：看清起手再滚（"看滚"） |
| 二连戳 | 0.35 | 0.14 | 0.9 | 连段意识：第一戳后别贪刀 |
| 横扫 | 0.70 | 0.20 | 0.95 | 后撤 vs 穿滚的抉择 |
| 下劈 | 0.85 | 0.14 | 1.10 | 侧滚方向教学（带小冲击环） |
| 跳劈 | 0.60 | 0.15 | **1.40** | **惩罚窗口教学**：远距离固定触发，落点大硬直 |
| 肩撞 | 0.40 | 0.12 | 0.70 | 近身解围，别贴脸贪刀 |
| 抓技 | 0.70 | 0.20 | 1.20 | 不可弹反/格挡的高压招，识别并后撤 |

规则：**全部戟招可弹反**（含跳劈）；削韧满 100 → 跪地开放 2.5s（承伤加成）；追踪弱、前摇明显——教学 Boss 的宽容度。

### 二阶段（HP ≤ 55% 触发）

- 变身爆发本身带判定（0.5s 震波，逼玩家撤开）——复刻古达变身细节
- 烬蛇承接部分攻击，戟保留：
  - **烬蛇横扫**：范围 ×1.6，前摇 0.80 / 判定 0.25 / 后摇 1.0
  - **烬蛇突刺**：射程 8m 远程威胁，前摇 0.70 / 判定 0.18 / 后摇 0.9
  - **火痕残留**：招式落点留 2s 灼烧地面，控制走位空间
- 移速 −15%、动作更慢但距离压力陡增——"节奏变形"式二阶段

## 三、从古达学到的设计铁律（拉片结论）

1. **每招即教学**：首 Boss 的招式表就是关卡设计，按"滚的方向/时机/贪刀成本"递进排布
2. **远距离固定出跳劈** = 内建的惩罚窗口教学，用 1.4s 后摇奖励读懂它的人
3. **弱追踪 + 长前摇**：教学 Boss 的宽容度不靠数值，靠可读性
4. **变身带判定**：阶段转换同时是威胁、奇观与节奏重置
5. **唤醒序列的先手权**：让玩家在血条出现前打出优势——紧张感前的掌控感
6. **可弹反全部招式**：教学关就把技巧天花板亮出来，弹反收益前置

## 四、与现有系统的对接

- 帧数据 → 手感档案（feel profile）进调校台热调；上表秒数即初值
- 削韧/破绽 → ADR-0004 状态机；弹反→处决 → ADR-0008 剑盾招牌
- 烬蛇/火痕 → 火光粒子通道（combat-feel.md 六通道的"火金"主色板）
